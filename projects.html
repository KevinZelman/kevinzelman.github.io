Known Good Process Tree

A help desk reference for any organization

Every request that reaches IT starts with the same question: is this ours? The Process Tree answers it, then walks the request all the way to a clean, copy-ready ticket: who owns it, how urgent it is, and the exact steps to finish it.

It maps 64 standard operating procedures across four support tiers, from the front door to IT management. When a request belongs to HR, Finance, Facilities or another department, it says so and helps the technician hand it off cleanly.

The language is deliberately universal, so it fits education, healthcare, finance, nonprofits or anywhere else. It runs entirely in your browser, and the source is open under a Creative Commons license, so you can fork it and make it yours.

Account Manager · live demo

One window for AD and Entra accounts

Account Manager is a Windows console for small IT teams: unlock, reset, lock down and offboard people across on-prem Active Directory and Microsoft Entra in one place, with mailbox tools and threat triage alongside.

The live demo runs in your browser with invented people at a fictional organization. Every button works against that sample data, including the failures, so you can see how each error explains what happened and what to try next.

The companion guide shows how to do every action by hand: the admin portal path and the PowerShell.
